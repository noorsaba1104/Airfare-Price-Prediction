# ✈️ Airfare Price Prediction

**Tagline:** _"Predict the Price Before You Fly."_

This project predicts airfare prices using machine learning and provides a web-based interface built with Django. It helps users estimate flight prices based on key travel details, enabling informed decisions and smarter travel planning.

---

## 🧠 Problem Statement

Airfare pricing is highly dynamic and influenced by several factors including airline, route, date, number of stops, and duration. The lack of price transparency often results in suboptimal travel decisions. This project aims to solve this by building a predictive model that estimates flight prices based on historical data and deploys it via a user-friendly web interface.

---

## 🎯 Objectives

- Clean and preprocess raw flight data for analysis  
- Perform exploratory data analysis (EDA) to uncover insights  
- Build and evaluate machine learning models to predict flight prices  
- Develop a web application for users to input flight details and get predicted prices  
- Deploy the solution using Django framework for real-time usage

## 📁 Dataset Overview

The dataset includes:
- Airline  
- Date of Journey  
- Source and Destination  
- Route and Duration  
- Total Stops  
- Price (target variable)

> Data preprocessing includes conversion of string-based durations, date-time formatting, and one-hot encoding for categorical variables.

---

## 📈 Model Performance

- **Best Model:** Random Forest Regressor  
- **Evaluation Metrics:** R² Score, MAE, RMSE  
- Achieved R² Score: ~0.82  
- Reliable predictions with low error on test data
